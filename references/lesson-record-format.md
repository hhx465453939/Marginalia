# 批注本格式规范

**一个文件 = 一本书 = 一位学员**：文件头课程卡（管理）+ 全书原文（一字不改）+ 批注层（对话长在原文边上）。

> **`book.md` 是渲染物，不是真源。**
> 真源是 `meta.json`（进度）+ `annotations.jsonl`（批注）+ `source.md`（原文）。
> 手改 `book.md` 会在 `verify --check-render` 里被检出，改完也会被下次 `render` 覆盖。
>
> - 模式 A：`marginalia render --as <uid> --book <slug>`
> - 模式 B（无 shell）：按本规范手写，并用 §4 的"书房指针"保证归属

---

## 1. 文件头课程卡

```markdown
# 《书名》·共读批注本（<称呼>）

- 学员：<称呼>（uid: <uid>）
- 底本：<版本 + 来源>
- 开课日期：<YYYY-MM-DD>
- 状态：进行中 / 暂停 / 已结课
- 更新时间：<YYYY-MM-DD HH:MM 北京时间>
- 批注条数：<N> ｜ 已讲篇目：<x>/<y>

## 全书地图

| 篇目 | 状态 |
|------|------|
| 捭阖第一 | 已讲 |
| 反应第二 | 未讲 |

## 当前进度

- 讲到：<篇名>·<段>
- 锚点："<最后讲完的原句>"

## 下次接续点

- <篇名>·<段>："<下一段开头原句>"
```

**`- 学员：` 这一行是隔离的锚点**：没有它，就无法判定这本批注本属于谁（`lint` 的 L1）。

`<称呼>` 必须与注册表逐字一致——它是批注里 `👤` 标签的唯一合法值。

---

## 2. 正文批注层

原文保持书稿原样（含标题层级），**一字不改**。每个讲过的段落之后紧跟批注块，中间**必须隔一个空行**（否则 Markdown 会把引用块当成段落续行）。

```markdown
<原文段落……>

> 🦞 **【第1课·2026-11-16】** 白话直译 + 解读 + 结合该学员实际的用法……
>
> 👤 **<称呼>**：<学员的提问、观点与读盘（尽量记原话）>
>
> 💬 **讨论**：<师生讨论结论；AI 的个人理解单独标注>
>
> ✅ **进度**：本段完于 2026-11-16
```

### 标签速查

| 标签 | 用途 | 承载"人" |
|---|---|---|
| `🦞 **【第N课·日期】**` | 讲解：白话 / 解读 / 用法 | 老师（AI） |
| `👤 **<称呼>**：` | 该学员的提问、观点与读盘（**记原话**） | ✅ **唯一** |
| `💬 **讨论**：` | 师生讨论结论 | ❌ |
| `✅ **进度**：` | 该段讲授完成的时间锚 | ❌ |
| `🔖 **异文**：` | 版本校记 | ❌ |

**只有 `👤` 后面写人名。** `💬 **讨论**`、`✅ **进度**` 里的加粗是**标签**，不是署名——把它当说话人，正是串档判断出错的源头之一。

### 锚点规则

- 锚点 = **逐字**摘自该段原文的一句；
- 必须在该书 `source.md` 中**唯一**出现（代码忽略空白差异，但要求唯一）；
- 若一句话在书中反复出现（金句、套语），把锚点加长到能唯一定位为止；
- 宁可报错，不要猜位置。

---

## 3. 隔离与交付

- 批注本属于学员本人：他的提问原话不得混入他人批注本，不得向第三方展示。
- 结课 / 导出：整文件即交付物，文件名形如 `《鬼谷子》·共读批注本.md`，发给**本人**。
- 删除请求：本人确认后移入 `users/<uid>/_trash/`，不直接删。

---

## 4. 模式 B 的「书房指针」（无 shell 时必用）

没有代码替你派生路径时，用一个**逐字复制的指针**代替：

```markdown
<!-- 每次会话开始，从 study/USERS.md 原样抄下当前学员这一行 -->
uid: <uid> | 称呼: <称呼> | 书房: study/users/<uid>/
```

落笔前三问：

1. 这份文件的课程卡 uid，与指针里的 uid 是否相同？
2. 我要写的 `👤` 标签，与指针里的称呼是否**逐字**相同？
3. 我的写入路径是否以指针里的 `书房:` 开头？

三问有一问答不上，**不要写**。

---

## 5. 可选的机器标记（便于事后审计）

```markdown
<!-- marginalia:uid=owner -->
```

放在文件首行。`lint` 会校验它与课程卡 uid 一致（L3）。有 shell 时由 `render` 自动写入。

---

## 6. 事后自检清单（无 shell 人工版）

- [ ] 课程卡有 `学员：<称呼>（uid: ...）`
- [ ] 标题括号里的称呼与课程卡一致
- [ ] 所有 `👤 **X**` 的 X 都是同一个人
- [ ] 没有出现其他学员的称呼
- [ ] 原文与底本逐字一致（没被"顺手润色"）
- [ ] 每个锚点在原文中只出现一次
- [ ] 引用块前有空行
